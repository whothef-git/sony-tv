# Current Octahedron screenshots

The current screenshots are direct 1920 × 1080 Sony BRAVIA captures taken on 30–31 October 2026:

- [Home](octahedron-home.png)
- [Prayer Time](octahedron-prayer-time.png)
- [Weather](octahedron-weather.png)
- [Smart Home](octahedron-smart-home.png)

They show Octahedron v3.0 (`versionCode 13`, package `tv.widgetv.home`). Clocks, calendar content, weather, and device states reflect the time of capture. No device control commands were sent to prepare these screenshots.

The capture build was the optimized, signed `Octahedron-v3.0.apk` (934,131 bytes). Its SHA-256 is `4b710192928e3492d41be6334ca09db6bb2ff527bd87d334b7a1c3863e2e04d5`. Android build tools verified the version, application label and signature; the certificate matched the previously installed APK, allowing an in-place TV update. Generated APKs remain outside Git.

Other screenshot filenames in this directory are historical WidgeTV captures retained for older documentation; they are not the current Octahedron preview.

Prayer Time shows the Quran-card preview from feature/quran-prayer-verses (same v3.0/versionCode 13), captured on 31 October with the official KFGQPC Hafs Uthmanic font, Arabic/Malay spacing and reference directly below the translation, with the provider footer hidden. The preview APK is Octahedron-Quran-Verse.apk (1,081,759 bytes), SHA-256 14e3dcf1a0213e5c0089f4d3c49fc95c8ec19a7e3b3e61dacfb1500e1283c1d3. Home, Weather and Smart Home captures retain the stable-main provenance above. No device-control commands were issued.
